## 🚀 로컬 실행 방법

브라우저의 ES Modules(`type="module"`) 보안 정책상 `file:///` 직접 열기 대신 **로컬 HTTP 서버** 환경에서 실행해야 정상적으로 모듈이 로드됩니다.

### Python을 사용하는 경우 (권장)

터미널에서 `web/` 디렉토리로 이동 후 아래 명령어를 실행합니다:

```bash
# web 폴더 안에서 실행
python -m http.server 8080
```

실행 후 브라우저에서 `http://localhost:8080` 으로 접속합니다.

## 🔍 주요 구현 기능

1. **실시간 KST 일정 판정**: 사용자 기기의 시계 설정과 관계없이 `Intl.DateTimeFormat(timeZone: 'Asia/Seoul')`을 통해 오픈 예정, 당일 정오 대기, 진행 중, 종료 상태를 정확히 판정 및 뱃지 표시.
2. **인터랙티브 가격 계산기**:
   - 0~1개 선택 시: 정상가 표시 및 "1개 더 담으면 20% 할인" 유도 메시지.
   - 2개 이상 선택 시: 정상가 취소선, 20% 할인액(`-000원`), 최종 예상가(`8,800~9,920원`), 2개 선택 시 1끼 환산가 자동 계산.
   - 하루 한도 40개 도달 시 `+` 버튼 자동 비활성화 및 경고 토스트.
3. **원클릭 추천 조합 프리셋**: 인기 1위 '영양 균형 세트', '매콤 밸런스 세트', '든든 탄수화물 세트', '가벼운 건강 세트' 즉시 적용.
4. **웹 접근성 (WCAG 2.1 AA)**: 스크린리더를 위한 `aria-live="polite"`, 키보드 조작(`Tab`, `Enter`), `:focus-visible` 고대비 아웃라인, 네이티브 `<details>` FAQ 지원.
